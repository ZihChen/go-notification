### 發現的問題

#### 1. Pipeline方法存在nil pointer風險
```go
// manager.go:181-187 當前實現
func (m *Manager) Pipeline() redis.Pipeliner {
    client, err := m.GetClient()
    if err != nil {
        return nil  // 返回nil可能導致panic
    }
    return client.Pipeline()
}
```

**問題描述**: 如果GetClient失敗，返回nil會導致調用方可能出現panic。

**實際影響**: 在`kds/consumer.go:394`中確實存在這個問題:
```go
pipeline := k.redisManager.Pipeline()  // 可能返回nil
// 如果pipeline是nil，下面的調用會panic
pipeline.Set(ctx, key, "1", eventProcessedTTL)
_, err := pipeline.Exec(ctx)
```

#### 2. 健康檢查可以更精確
```go
// distributed_lock.go:91-98 當前實現
func (r *RedisDistributedLockManager) IsAvailable() bool {
    _, err := r.manager.GetClient()
    return err == nil  // 只檢查client是否存在
}
```
**問題描述**: 只檢查client是否初始化，沒有實際測試Redis連通性。

#### 3. 重連間隔可以優化
```go
// manager.go:67 當前實現
time.Sleep(3 * time.Second)  // 固定間隔
```
**問題描述**: 固定3秒間隔，可以改為指數退避，減少不必要的重試壓力。

## 優化方案

### 方案1: Pipeline方法安全性改進 (強烈推薦)
**影響**: 極小，只是方法簽名變更
**收益**: 消除實際存在的nil pointer風險

#### 修改Manager.Pipeline方法:
```go
// 修改後的Pipeline方法
func (m *Manager) Pipeline() (redis.Pipeliner, error) {
    client, err := m.GetClient()
    if err != nil {
        return nil, fmt.Errorf("failed to get redis client for pipeline: %w", err)
    }
    return client.Pipeline(), nil
}
```

#### 更新調用方 (kds/consumer.go):
```go
// 修改前
pipeline := k.redisManager.Pipeline()
for _, eventID := range eventIDs {
    if eventID != "" {
        key := processedEventKeyPrefix + eventID
        pipeline.Set(ctx, key, "1", eventProcessedTTL)
    }
}
if _, err := pipeline.Exec(ctx); err != nil {
    // 錯誤處理
}

// 修改後
pipeline, err := k.redisManager.Pipeline()
if err != nil {
    k.logger.WarnWithContext(ctx, "Failed to get Redis pipeline", 
        k.logger.Error("err", err))
    return
}

for _, eventID := range eventIDs {
    if eventID != "" {
        key := processedEventKeyPrefix + eventID
        pipeline.Set(ctx, key, "1", eventProcessedTTL)
    }
}
if _, err := pipeline.Exec(ctx); err != nil {
    k.logger.WarnWithContext(ctx, "Failed to batch mark events as processed",
        k.logger.Error("err", err))
}
```

### 方案4: 優化重連策略 (可選)
**影響**: 小，只影響重連行為
**收益**: 減少對Redis server的重連壓力

#### 修改Connect方法中的重連邏輯:
```go
func (m *Manager) Connect(ctx context.Context) error {
    m.mu.Lock()
    defer m.mu.Unlock()

    if m.client != nil {
        return nil
    }

    retryCount := 0
    maxRetries := 5

    for {
        select {
        case <-ctx.Done():
            return fmt.Errorf("context cancelled while trying to connect to Redis: %w", ctx.Err())
        default:
            client := redis.NewClient(&redis.Options{
                Addr:            fmt.Sprintf("%s:%d", m.config.Redis.Domain, m.config.Redis.Port),
                Password:        m.config.Redis.Password,
                DB:              m.config.Redis.DB,
                PoolSize:        m.config.Redis.PoolSize,
                MinIdleConns:    m.config.Redis.MinIdleConns,
                MaxRetries:      m.config.Redis.MaxRetries,
                DialTimeout:     m.config.Redis.DialTimeout,
                ReadTimeout:     m.config.Redis.ReadTimeout,
                WriteTimeout:    m.config.Redis.WriteTimeout,
                PoolTimeout:     m.config.Redis.PoolTimeout,
                ConnMaxIdleTime: m.config.Redis.IdleTimeout,
                ConnMaxLifetime: m.config.Redis.MaxConnAge,
            })

            pool := goredis.NewPool(client)
            rs := redsync.New(pool)

            if err := client.Ping(ctx).Err(); err != nil {
                retryCount++
                if retryCount >= maxRetries {
                    _ = client.Close()
                    return fmt.Errorf("failed to connect to Redis after %d attempts: %w", maxRetries, err)
                }
                
                // 指數退避，最大30秒
                backoff := time.Duration(1<<uint(retryCount)) * time.Second
                if backoff > 30*time.Second {
                    backoff = 30 * time.Second
                }
                
                log.Printf("Failed to connect to Redis (attempt %d/%d): %v, retrying in %v...", 
                    retryCount, maxRetries, err, backoff)
                
                _ = client.Close()
                time.Sleep(backoff)
                continue
            }

            m.client, m.redsync, m.isClosed = client, rs, false
            log.Printf("Successfully connected to Redis at %s:%d", 
                m.config.Redis.Domain, m.config.Redis.Port)
            return nil
        }
    }
}
```
