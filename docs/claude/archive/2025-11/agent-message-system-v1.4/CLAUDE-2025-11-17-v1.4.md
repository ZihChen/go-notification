## 技術架構 (Technical Architecture)

### 修復的關鍵問題

#### 1. BackfillMissedMessages Nil Agent 檢查
**位置**: `internal/application/usecase/agent/agent_usecase.go:1093`
**問題**: `agentRepo.GetByGlobalID()` 返回nil後未檢查直接使用 `agent.ID`
**修復**: 
```go
// 如果代理不存在，無需補派發（可能是新代理或已被刪除）
if agent == nil {
    u.tracingService.TraceEvent(span, "Agent not found, skipping backfill")
    u.logger.InfoLog("Agent not found, skipping backfill",
        u.logger.String("global_agent_id", agentEvent.GlobalAgentID))
    return nil
}
```

#### 2. shouldAgentReceiveLineCampaign Parent Agent 檢查
**位置**: `internal/application/usecase/agent/agent_usecase.go:1304`
**問題**: `agentRepo.GetByAccount()` 返回nil後未檢查直接使用 `parentAgent.GlobalAgentID`
**修復**:
```go
// 如果父代理不存在，該 line 活動無效
if parentAgent == nil {
    return false, fmt.Errorf("parent agent not found with account: %s", parentAccount)
}
```

#### 3. SyncAgentRelationshipsUpsert Merchant 檢查
**位置**: `internal/application/service/agent_service.go:63`
**問題**: `merchantRepo.FindByGlobalID()` 返回nil後未檢查直接使用 `merchant.ID`
**修復**:
```go
if merchant == nil {
    s.tracingService.TraceEvent(span, "Merchant not found, skipping agent relationship sync")
    s.logger.WarnLog("Merchant not found for agent relationship sync",
        s.logger.String("global_merchant_id", agentEvent.GlobalMerchantID),
        s.logger.String("global_agent_id", agentEvent.GlobalAgentID))
    return nil
}
```

### 補派發功能擴展架構

#### Target Type 支援矩陣
| Target Type | 匹配邏輯 | 實現方法 | 效能特性 |
|-------------|----------|----------|----------|
| `all` | 所有代理都接收 | 直接返回 true | O(1) |
| `specific` | 帳號精確匹配 | 列表包含檢查 | O(n) |
| `line` | Ancestry 路徑匹配 | 字串包含檢查 | O(1) |

#### 智能匹配算法
```go
// Specific Type 匹配邏輯
func shouldAgentReceiveSpecificCampaign(agent *entity.Agent, campaign *entity.AgentCampaign) bool {
    for _, targetAccount := range campaign.TargetDetails {
        if agent.Account == targetAccount {
            return true
        }
    }
    return false
}

// Line Type 匹配邏輯  
func shouldAgentReceiveLineCampaign(ctx context.Context, agent *entity.Agent, campaign *entity.AgentCampaign) (bool, error) {
    parentAccount := campaign.TargetDetails[0]
    parentAgent, err := u.agentRepo.GetByAccount(ctx, parentAccount)
    if err != nil {
        return false, fmt.Errorf("get parent agent by account: %w", err)
    }
    if parentAgent == nil {
        return false, fmt.Errorf("parent agent not found with account: %s", parentAccount)
    }
    
    if agent.Ancestry == "" {
        return false, nil // 頂級代理，無父代理關係
    }
    
    // 高效字串匹配
    return strings.Contains(agent.Ancestry, parentAgent.GlobalAgentID), nil
}
```
