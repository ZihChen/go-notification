# 會員訊息資料結構調整

## 完成狀態

## 功能概述
把紀錄會員訊息活動的status、category、item、target欄位從uint8改成string，更符合語意設計
避免管理enum type過度複雜

## 技術實作
- 將所有MessageCampaign相關Model、Entity裡的category、item、target從uint8改成string
- DB資料型別從tinyint改成varchar(255)
- 轉換內容如下:
  - status:
    - 1 -> draft
    - 2 -> scheduled
    - 3 -> sent
    - 4 -> cancelled
    - 5 -> failed
  - category:
    - 1 -> member
    - 2 -> bonus
    - 3 -> others
  - item:
    - 1 -> registration
    - 2 -> identity_verification
    - 3 -> bank_card
    - 4 -> others
    - 5 -> event
    - 6 -> all
    - 7 -> mission
  - target:
    - 1 -> high_activity
    - 2 -> low_activity
    - 3 -> not_activity
    - 8 -> player
    - 9 -> level
    - 10 -> tag
    - 11 -> all
- 給我一個UPDATE的SQL指令可以把當前的數字轉換成對應的字串
