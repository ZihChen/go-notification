# 會員訊息排程發送系統功能增強 v1.7

## 完成狀態

## 功能概述
可以針對特定多個玩家帳號、多個玩家等級、多個玩家標籤進行訊息發送

## 技術實作
- 新增兩支API
  - 取得PlayerLevel的列表
  - 取得PlayerTag的列表
- FindByTargetType的function要新增：
  - consts.TargetPlayer
  - consts.TargetLevel
  - consts.TargetTag
- 修改創建/更新CampaignMessage的API
  - Target參數如果帶player、level、tag其中一個，就要在TargetDetail傳入Slice
    - player存放account，["max123", "winston888"]
    - level存放id，[1,12,123]
    - tag存放id，[1,12,123]
  - 存到資料庫以player的account、level的name、tag的name為主，取得會員訊息就不用再搜尋一次
- 發送邏輯：
  - 透過player的account Slice找到對應的玩家做發送
  - 透過level的Slice找到對應等級的玩家做發送
  - 透過tag的Slice找到對應標籤的玩家做發送
