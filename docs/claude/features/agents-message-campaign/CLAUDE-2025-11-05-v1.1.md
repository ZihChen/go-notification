## 🔄 **代理關係同步流程**

### 核心流程圖
```
KDS Event → Worker Handler → AgentUseCase → AgentService → Repository
     ↓              ↓              ↓            ↓           ↓
AgentSyncEvent → HandleAgentSync → Sync Flow → Parse/Build → DB Update
```

### 詳細執行步驟

1. **事件接收**: Worker Handler接收AgentSyncEvent
2. **資料同步**: AgentUseCase協調代理基本資料同步
3. **關係解析**: AgentService解析ancestry路徑
4. **批量處理**: 批量獲取或創建所有代理
5. **關係建立**: 建立每層父子關係鏈
6. **併發安全更新**: 分佈式鎖保護下的批次更新
7. **追蹤記錄**: 完整的OpenTelemetry追蹤鏈

### 併發安全保證

```go
// 智能分組策略
lockKey := fmt.Sprintf("agent_relationship:batch_update:%d", targetAgentID)

// 分佈式鎖配置
lockOptions := infrastructure.LockOptions{
    Expiry:     30 * time.Second,       // 鎖過期時間
    Tries:      5,                      // 重試次數
    RetryDelay: 100 * time.Millisecond, // 重試間隔
}

// UPSERT邏輯處理衝突
clause.OnConflict{
    Columns: []clause.Column{{Name: "parent_id"}, {Name: "child_id"}},
    DoUpdates: clause.AssignmentColumns([]string{
        "depth_level", "path_hash", "updated_at",
    }),
}
```
